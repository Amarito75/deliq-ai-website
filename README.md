# Decliq.ai — Landing page

Landing page premium pour **Decliq.ai**, plateforme d'agents IA pour indépendants, TPE et PME françaises.

Stack : **Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · next/font (Google Fonts)**.

## Aperçu design

- Aesthetic premium dark — fond `#0b0b0d`, off-white `#f3efe6`, accent violet `#8b5cff`, accent secondaire lime `#d8ff3a`
- Typographie éditoriale : **Fraunces** (display italic) + **Instrument Serif** + **Inter** + **JetBrains Mono**
- Texture noise globale, blobs animés, marquee géant, cards magnétiques
- 24 agents répartis en 6 catégories, grille filtrable + modal détaillée
- Calendrier de réservation interactif (placeholder Calendly stylé)

## Sections

1. Hero éditorial XXL
2. Marquee italique
3. Stats (4 chiffres clés)
4. Comment ça marche (4 étapes)
5. Grille filtrable des 24 agents
6. Témoignages clients (bento grid)
7. Calendrier de réservation
8. FAQ
9. CTA banner
10. Footer

## Démarrage

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # build production
npm start        # serve build
```

## Déploiement

Optimisé pour Vercel — un push sur `main` suffit.
